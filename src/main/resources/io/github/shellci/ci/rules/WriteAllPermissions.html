permissions: write-all gives the job's GITHUB_TOKEN write access to contents, packages, pull requests, issues, deployments, workflows and every other scope. Any compromised step or dependency can then push code, publish packages or approve its own changes.

Ask Yourself Whether

  • The job really needs to write to more than one or two scopes.
  • The job runs third-party actions or installs dependencies.

There is a risk if you answered no to the first question or yes to the second.

Recommended Secure Coding Practices

Grant only the scopes the job needs, ideally per job.

Sensitive Code Example

permissions: write-all  # Sensitive

Compliant Solution

permissions:
  contents: read
  pull-requests: write
