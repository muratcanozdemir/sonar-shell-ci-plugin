secrets: inherit passes every secret available to the calling workflow to the reusable workflow. When that workflow lives in another repository, its owner (or anyone who can change it, or the ref you point to) receives secrets it may not need.

Ask Yourself Whether

  • The reusable workflow is maintained outside this repository.
  • It needs only some of the secrets.

There is a risk if you answered yes to any of those questions.

Recommended Secure Coding Practices

Pass only the secrets the workflow declares it needs.

Sensitive Code Example

jobs:
  release:
    uses: other-org/workflows/.github/workflows/release.yml@3f2a7c9e1b4d5f6a7b8c9d0e1f2a3b4c5d6e7f80
    secrets: inherit  # Sensitive

Compliant Solution

jobs:
  release:
    uses: other-org/workflows/.github/workflows/release.yml@3f2a7c9e1b4d5f6a7b8c9d0e1f2a3b4c5d6e7f80
    secrets:
      npm-token: ${{ secrets.NPM_TOKEN }}
